# المرحلة الثالثة: محادثات الشغل

الحالة: معاينة أصلية من 22 نوفمبر. التنفيذ المحلي الأحدث واختباراته في docs/plan/remaining-features-ar.md. لا نشر ولا رفع فروع.

## المعاينة
- ثلاثة مواقف عامة وخيالية: متابعة مورّد، تحديث عميل، وتحديث فريق.
- اختيار الموقف يعرض ثلاثة أهداف واضحة.
- نفس ألوان وخط ومكونات لسان الحالية، بالعربي والإنجليزي.
- اختيار الكارت لا يستدعي خدمة الذكاء الاصطناعي. بدء المحادثة يستخدم المسار الموجود وحصصه الحالية.
- صفحة المعاينة المؤقتة غير موجودة في مسارات التطبيق النهائية. مصدرها محفوظ هنا لإعادة المعاينة فقط.

## بعد اعتماد الشكل
- تضمين أهداف الموقف في تعليمات الشريك والتقرير، دون ادعاء تقييم لم نختبره.
- حفظ مفردات المدرس للمراجعة من الرسالة الأصلية مع تحقق ملكية المحادثة، دون الوثوق بكلمات يرسلها المتصفح.
- الاحتفاظ بمسار المحادثة الأصلي عند الحفظ حتى لو تغيّر المسار النشط.
- منع تكرار الحفظ أو إعادة ضبط توقيت المراجعة لكلمة موجودة.
- اختبارات ملكية البيانات، فشل الخدمة ونفاد الحصة، حفظ الكلمات، والتدفق على الهاتف.
