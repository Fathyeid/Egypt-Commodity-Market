# المدرسة بدون نت والحكايات التفاعلية

محليًا، النشر ينتظر المعاينة والموافقة.

## الأوفلاين
- تنزيل حتى 20 درسًا مع المحتوى العام والتدريبات والاختبار، بدون مفاتيح الإجابات أو جلسة الدخول.
- حزمة موقعة للحساب والمسار وإصدار المحتوى، صالحة 30 يومًا. تغيير المحتوى يطلب تنزيل نسخة جديدة.
- حفظ إجابات الاختبار والتدريبات الاختيارية صراحة على الجهاز، حد 100 محاولة. لا حفظ تلقائي للنص غير المرسل قبل إغلاق الصفحة.
- مكتبة محلية ومركز مزامنة يدوي. تسجيل الدخول بنفس الحساب مطلوب للمزامنة، والعودة لنفس المسار مطلوبة للمحاولة الجديدة.
- تصحيح الخادم فقط، إيصال دائم وقفل معاملات يمنعان تكرار النقاط عند إعادة الطلب أو ضياع الرد. النقاط بتاريخ المزامنة، لا تعويض سلسلة الأيام القديمة.
- الإيصال والتقدم والنقاط وكلمات الدرس داخل معاملة واحدة. المحاولة المصححة محليًا تبقى حتى الحذف أو الخروج.
- التخزين محلي غير مشفر. لا استخدام على جهاز مشترك؛ مسح عند الخروج أو دخول حساب آخر، ومسح يدوي بتأكيد.
- الفيديو أونلاين، صوت المتصفح قد يحتاج اتصالًا. المحتوى والنص والاختبار يعملون بدون نت بعد التنزيل.

## الحكايات
- أربع قصص أصلية: إنجليزي وألماني، A1 وA2. غير ذلك يعرض رسالة صريحة ويترك مراكز القراءة والاستماع الموجودة.
- مساران لكل قصة، أربع مشاهد مع ردود المتعلم، ترجمة اختيارية وصوت المتصفح لكل مقطع.
- الاختيارات تغيّر الحوار ولا تعطي درجة. أسئلة الفهم بعد النهاية، التصحيح على الخادم، مع تحقق المسار واللغة والحساب.
- حفظ أفضل نتيجة، و15 XP لأول اجتياز 70% فقط. إعادة الحكاية لا تكرر المكافأة، حتى مع طلبين متوازيين.
- لا مدة تعلم مصطنعة: القصة تسجل نقاطها بمدة صفر بدل قبول مؤقت غير موثوق.

## البيانات والتكلفة
- جدول جديد learning_receipts فقط. لا حذف أو إعادة بناء أو تحويل بيانات قديمة.
- لا خدمة أو اشتراك مدفوع جديد. لا Preview لأن قاعدة بياناته مشتركة مع الإنتاج.
- اختبار محلي بقاعدة منفصلة، وفحص بصمات بيانات المتعلمين قبل/بعد أي نشر معتمد.
